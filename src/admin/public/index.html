Informe o nome exato de uma instância já existente na Evolution. Configure o webhook dessa instância para este bot. Ao salvar, esta distribuidora passa a usar a nova instância; o histórico da anterior é preservado.

O token é salvo sem ser exibido novamente. Informe um valor para cadastrar ou substituir; deixe vazio para manter o token já salvo.

Ao mudar a instância, informe o token correspondente ou selecione a chave global. A chave global configurada no servidor continua sendo usada se esta opção estiver marcada.

Botões usam os nomes dos representantes (até 20 caracteres e 3 contatos). O suporte e a disposição dependem da Evolution e do WhatsApp. Em Contatos (vCard), são enviadas a saudação e depois os contatos agrupados, sem mensagem pré-preenchida. Na lista, o cliente escolhe um nome e recebe o link em outra mensagem. Para testar, salve, libere seu contato abaixo e envie uma nova mensagem ao bot.
